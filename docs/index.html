🔧 Metal Calculator API

Калькулятор металлопроката для n8n на Railway

О проекте

Metal Calculator - это библиотека для расчета веса, длины и количества металлопроката. База данных содержит 70 типов металлов с подробными характеристиками, включая арматуру, балки, швеллеры, уголки, трубы и многое другое.

  • Расчет по весу → длина + количество штук
  • Расчет по длине → вес + количество штук
  • Расчет по количеству → вес + длина
  • Поддержка оцинкованных изделий
  • Точные формулы расчета для различных профилей
  • Более 70 типов металлопроката

Использование в n8n

Шаг 1: Code Node - Загрузка ресурсов

Создайте Code Node и загрузите необходимые ресурсы:

// Загрузка базы данных металлов
const metalsResponse = await fetch(
  'https://your-username.github.io/metal-calculator/database/metals.json'
);
const metalDatabase = await metalsResponse.json();

// Загрузка калькулятора
const calcResponse = await fetch(
  'https://your-username.github.io/metal-calculator/dist/calculator.bundle.js'
);
const calcCode = await calcResponse.text();

// Выполнение кода калькулятора
const { calculateMetal } = eval(calcCode + '; ({ calculateMetal })');

// Теперь можно использовать calculateMetal
return { metalDatabase, calculateMetal };

Шаг 2: Выполнение расчета

Используйте функцию calculateMetal для расчетов:

// Пример: расчет арматуры А3, d=12мм, вес=100кг
const result = calculateMetal({
  metalType: 'armature_a3',
  size: 12,
  weight: 100
}, metalDatabase);

// Результат:
// {
//   success: true,
//   metalType: "Арматура А3",
//   size: 12,
//   gost: "ГОСТ 5781-82",
//   category: "Арматура",
//   weightPerMeter: 0.888,
//   weight: 100,
//   length: 112.64,
//   pieces: 10,
//   isGalvanized: false
// }

return result;

Параметры функции calculateMetal

{
  metalType: string,      // Тип металла ('armature_a1', 'beam', 'channel', и т.д.)
  size: number|string,    // Размер (12 для арматуры, '20К1' для балки)
  weight: number?,        // Вес в кг (опционально)
  length: number?,        // Длина в метрах (опционально)
  pieces: number?,        // Количество штук (опционально)
  isGalvanized: boolean?, // Оцинкован? (опционально)
  galvCoef: number?       // Коэффициент оцинковки: 0.03, 0.05, 0.07 (опционально)
}

Примеры использования

// Пример 1: Балка 20К1, длина 50м
const result1 = calculateMetal({
  metalType: 'beam',
  size: '20К1',
  length: 50
}, metalDatabase);

// Пример 2: Арматура А1 оцинкованная, 5 штук по 12м
const result2 = calculateMetal({
  metalType: 'armature_a1_galv',
  size: 10,
  pieces: 5,
  isGalvanized: true,
  galvCoef: 0.03
}, metalDatabase);

// Пример 3: Швеллер 10У, вес 200кг
const result3 = calculateMetal({
  metalType: 'channel',
  size: '10У',
  weight: 200
}, metalDatabase);
