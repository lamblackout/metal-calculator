## 🎯 ОБЗОР ПРОЕКТА

### Назначение
Калькулятор металлопроката для автоматического расчёта веса, длины и количества штук металла с округлением кратно целым штукам.

### Ключевые особенности
- ✅ 76 типов металла, 5,700+ размеров
- ✅ Автоматическое округление кратно штукам (всегда вверх)
- ✅ Пересчёт всех параметров от округлённых штук
- ✅ Взаимозависимые поля (заполнил одно → остальные автоматом)
- ✅ Формулы по ГОСТам
- ✅ Готов к интеграции с n8n

### Технологии
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend:** Node.js (для тестов и сборки)
- **Bundle:** Custom build script
- **Деплой:** GitHub Pages
- **Тесты:** Custom test scripts

## 🧠 АРХИТЕКТУРА КОДА

### 1. Основная логика (src/calculator.js)

**Главная функция:** `calculateMetal(params, metalDatabase)`

**Входные параметры:**
```javascript
{
  metalType: 'armature_a3',        // Тип металла
  size: 12,                        // Размер
  weight: 1,                       // Вес в тоннах (опционально)
  length: 1000,                    // Длина в метрах (опционально)
  pieces: 86,                      // Штуки (опционально)
  steelType: 'ст3'                // Марка стали (для катанки)
}
```

**Выходные данные:**
```javascript
{
  success: true,
  metalType: "Арматура А3",
  size: 12,

  // Запрошенные значения
  requested: {
    value: 1000,
    unit: "length",
    label: "1000 м"
  },

  // Фактические значения (кратно штукам)
  actual: {
    weight: 0.893,      // т
    length: 1006.2,     // м
    pieces: 86          // шт
  },

  // Разница
  difference: {
    length: "+6.2 м"
  },

  // Дополнительно
  weightPerMeter: 0.888,
  standardLength: 11.7,
  gost: "ГОСТ 5781-82"
}
```

### Ключевая логика округления

**Алгоритм:**

1. Пользователь вводит значение (например, 1000м)
2. Рассчитываем промежуточное количество штук: `1000 / 11.7 = 85.47`
3. Округляем ВВЕРХ: `Math.ceil(85.47) = 86` штук
4. Пересчитываем от штук:
   - Длина: `86 × 11.7 = 1006.2` м
   - Вес: `1006.2 × 0.888 = 893.5` кг

**Код (src/calculator.js:146-163):**
```javascript
} else if (params.length) {
  const requestedLength = params.length;
  const pieceLength = standardLength || 1;  // Fallback на 1 метр

  // Округляем штуки ВВЕРХ
  pieces = Math.ceil(requestedLength / pieceLength);

  // Пересчитываем от округлённых штук
  length = pieces * pieceLength;
  const actualWeightKg = weightPerMeter * length;
  weight = actualWeightKg / 1000;
}
```

### Обработка разных типов металла

**1. Стандартные металлы (арматура, балки, швеллеры)**
- Формула: `масса_метра × длина`
- Пример: Арматура 12мм = 0.888 кг/м

**2. Катанка**
- Формула: `коэф_размера × коэф_стали`
- Зависит от марки стали (ст3, ст5, 45, и т.д.)

**3. Крепёж (болты, гайки, шайбы)**
- Вес на 1000 штук в БД
- Формула: `(вес_на_1000 / 1000) × количество`

**4. Листы**
- Формула: `толщина(мм) × ширина(м) × длина(м) × 7.85`

**5. Канаты**
- Табличные значения (`useKilograms: true`)

### 2. Формулы (src/formulas.js)

**Константы:**
```javascript
const STEEL_DENSITY = 7850;  // кг/м³ (плотность стали)
```

**Основные функции:**

**`calculateLengthFromWeight(weightKg, weightPerMeter)`**
```javascript
// Длина = Вес / ВесЗаМетр
return weightKg / weightPerMeter;
```

**`calculatePiecesFromLength(length, standardLength)`**
```javascript
// Штуки = ОКРУГЛЕНИЕ_ВВЕРХ(Длина / СтандартнаяДлина)
return Math.ceil(length / standardLength);
```

**`calculateSheetWeight(width, length, thickness)`**
```javascript
// Формула листов: толщина × ширина × длина × 7.85
const thicknessInMeters = thickness / 1000;
const volumeInM3 = width * length * thicknessInMeters;
return volumeInM3 * STEEL_DENSITY;
```

```html
  <option value="wire_rod">Катанка</option>

```

**2. Три взаимозависимых поля**
```html
<input id="input-weight" type="number" placeholder="0.000">
<input id="input-length" type="number" placeholder="0.00">
<input id="input-pieces" type="number" placeholder="0">
```

**Логика взаимозависимости:**
- Пользователь вводит в **любое** поле
- **Debounce 1500ms** (1.5 сек задержка)
- Вызывается `recalculateFields(sourceField)`
- Остальные два поля **автоматически заполняются**

**3. Секция результатов**
```

│ ИНФОРМАЦИЯ О МЕТАЛЛЕ (белый)   │

```

### Ключевые функции JavaScript

**`recalculateFields(sourceField)`**
- Определяет какое поле изменил пользователь
- Собирает параметры для `calculateMetal()`
- Вызывает калькулятор
- Заполняет остальные поля

**`displayResult(result)`**
- Формирует HTML результата
- Три секции: Информация / Запрошено / Фактически
- Зелёные бейджи с разницей

**`debounceRecalculate(sourceField, delay)`**
- Задержка 1500ms перед расчётом
- Позволяет вводить многозначные числа

## 🔑 КЛЮЧЕВЫЕ КОНЦЕПЦИИ

### 1. Округление кратно штукам

**Проблема:** Металл отгружается **целыми штуками**, нельзя отдать 0.47 штуки!

**Решение:**
- Всегда округляем **ВВЕРХ** (`Math.ceil`)
- Пересчитываем `length` и `weight` **от округлённых штук**
- Показываем разницу пользователю

### 2. Стандартные длины

**Концепция:**
- Каждый металл имеет `standardLengths: [6, 11.7, 12]`
- Калькулятор выбирает **приоритетную** длину:
  - Арматура: **11.7м** (с завода)
  - Балки/швеллеры: **12м**
  - Катанка/крепёж: **1м по умолчанию** (нет стандарта)

### 3. Взаимозависимые поля

**Принцип:**
- Заполнил **одно** поле → остальные автоматически пересчитываются
- Debounce 1.5 сек → можно вводить многозначные числа
- Нет кнопки "Рассчитать" → всё в реальном времени

### 4. Структура результата

**Три части:**
1. **requested** - что запросил пользователь (1000м)
2. **actual** - что фактически получит (1006.2м кратно штукам)
3. **difference** - разница (+6.2м)
